# Pranav Labs Logo Guidelines

> Version: 1.0
> Last Updated: September 2026

---

# Overview

The Pranav Labs logo is the primary visual identifier of the company.

It represents engineering precision, thoughtful design, reliability, and long-term thinking.

The logo should always appear clean, minimal, and consistent across every platform.

---

# Logo Components

The identity consists of:

1. Icon
2. Wordmark
3. Combined Logo

---

## Icon

The icon is the primary brand symbol.

It is designed to work independently at every size.

Use it for:

- Favicon
- Mobile App
- Social Media
- GitHub
- Product Icons
- Avatar
- Loading Screen

---

## Wordmark

Text only.

Used when the icon already exists elsewhere.

Example:

Navigation bars

Footers

Legal documents

---

## Combined Logo

Default brand lockup.

Use for:

- Website
- Presentations
- Business documents
- Marketing
- Email signatures

---

# Logo Variants

## Primary

Blue icon

Black wordmark

White background

Use whenever possible.

---

## Dark

White icon

White text

Dark background

Use for dark interfaces.

---

## Monochrome

100% Black

or

100% White

# Clear Space

Always leave empty space around the logo.

Minimum spacing equals:

```
1× icon width
```

No text, images, or UI elements should enter this area.

# Icon Usage

The icon may be used independently.

Examples:

- GitHub Organization
- LinkedIn Company
- WhatsApp Business
- Browser Favicon
- App Icon
- Documentation

The icon should never be stretched or cropped.

---

# Wordmark Usage

Typography must remain unchanged.

Never replace the font.

Never recreate the wordmark manually.

---

# Incorrect Usage

Never:

❌ Rotate

❌ Stretch

❌ Squash

❌ Change colors

❌ Add gradients

❌ Add shadows

❌ Add outlines

❌ Add glow

❌ Add bevel

❌ Change opacity

❌ Add effects

❌ Place inside random shapes

❌ Use low-resolution exports

---

# App Icon

The icon should be centered.

Padding:

15–20%

Corner radius follows the operating system.

Do not place text inside the app icon.

---

# Favicon

Use icon only.

No text.

Must remain recognizable at:

16 × 16

32 × 32

48 × 48

---

# Social Media

Use icon only.

Do not use the full logo.

Platforms:

- GitHub
- LinkedIn
- X
- Instagram
- WhatsApp Business
- YouTube
- Discord

---

# Ownership

The Pranav Labs logo is the primary intellectual property of Pranav Labs.

Any modification, recreation, or alternate interpretation should preserve the integrity of the original identity system.

---

# Final Rule

Never redesign the logo simply because trends change.

A strong logo becomes valuable through consistent use over many years.

Consistency builds recognition.

Recognition builds trust.

Trust builds great companies.
