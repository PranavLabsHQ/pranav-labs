- Premium
- Fast
- Focused

# Logo Rules

The logo represents engineering precision.

Never:

- stretch it
- rotate it
- add effects
- add shadows
- change proportions

Always maintain generous spacing around the mark.

# Iconography

Icons should be:

- consistent stroke width
- Lucide preferred

---

# Photography

Use:

- clean workspaces
- software interfaces
- engineering teams
- architecture
- technology

Avoid:

- fake smiling office photos
- generic stock photos
- overused AI imagery

---

# Animation Principles

Motion should guide attention.

Not entertain.

Allowed:

- fade
- slide
- hover
- text reveal
- subtle background movement

Avoid:

- parallax
- spinning objects
- floating cards
- excessive particle effects
- distracting motion

---

# Website Principles

The website should communicate:

"We build software."

—not—

"We know web design."

Products are always the hero.

Animations support content.

Never compete with it.
