# Decision Filter

Before starting any project, ask:

1. Does this solve a real problem?

2. Would someone pay for it?

3. Does it strengthen the Pranav Labs brand?

4. Does it improve our engineering capability?

5. Can it become a reusable product?

If most answers are "No",

do not build it.
