# Blog

This folder is the source area for long-form Pranav Labs writing.

The live website currently reads structured post metadata from `content/ecosystem.ts`
and mirrors MDX-ready source files in `content/blog/`. Future migration to a full
MDX pipeline should keep the public routes stable:

- `/blog`
- `/blog/[slug]`
- `/rss.xml`
